## 一、启用 AI 经营日报的真 AI 分析（R1 遗留，约 10 分钟）

- [ ] 1. 注册智谱开放平台 [bigmodel.cn](https://open.bigmodel.cn) → 实名 → 创建 API Key（glm-4-flash 有免费额度，日报一天一次费用可忽略）
- [ ] 2. 登录系统（admin/admin123）→ **系统设置 → 参数设置** → 找到「AI日报密钥」（`jxc.ai.apiKey`）→ 填入 Key 保存
- [ ] 3. **系统监控 → 定时任务** → 「AI经营日报」→ 操作「执行一次」→ 顶栏铃铛应出现【AI日报】且页脚标注"AI（glm-4-flash）生成"
- 参考口径：`docs/项目进度跟踪.md` §4.12；出错会自动降级模板（不影响任务），多为 Key 错误或网络问题

## 二、启用支付宝沙箱真实收款（R2 遗留，约 30 分钟）

- [ ] 1. 注册 [支付宝开放平台](https://open.alipay.com)（个人实名即可）→ 控制台 → **沙箱环境**
- [ ] 2. 记下沙箱 **APPID**；下载**支付宝密钥工具**生成 RSA2 密钥对；在沙箱页上传**应用公钥** → 获得**支付宝公钥**（⚠️ 不是应用公钥）
- [ ] 3. 参数设置填 3 项：「支付-沙箱应用ID」(appId)、「支付-应用私钥」(privateKey，PKCS8)、「支付-支付宝公钥」(publicKey)——改配置**不用重启后端**
- [ ] 4. 注册 [cpolar](https://www.cpolar.com)（免费）→ 建隧道指向 `localhost:8080` → 把公网地址填入「支付-回调外网地址」(`jxc.pay.notify.baseUrl`，如 `https://xxx.cpolar.io`)
- [ ] 5. 安卓手机安装**沙箱钱包 App**（沙箱控制台提供下载与测试买家账号）
- [ ] 6. 验证：收银台加购 → 「支付宝扫码收款（沙箱）」→ 沙箱钱包扫码付款 → 店内**语音播报到账 + 购物车自动结算**
- 参考：`docs/项目进度跟踪.md` §4.14；微信模拟通道现在就能演示，无需任何配置
