## 六、关键决策与经验记录

| # | 决策/经验 | 说明 |
|---|---|---|
| 1 | **JDK8 约束** | RuoYi-Vue 固定用 **v3.9.1**（master 3.9.2+ 需 JDK17）；构建前必须先停后端（jar 文件锁） |
| 2 | **前端 Vue3** | 采用官方 RuoYi-Vue3；gitee 源需认证，克隆走 GitHub 镜像 |
| 3 | **代码生成路线** | 统一 `tpl_web_type='element-plus'` 直出 Vue3 页面；主子表用 `tpl_category='sub'` + sub_table 配置 |
| 4 | **Vue3 页面规范** | `<script setup>` 页面末尾必须显式调用 `getList()`；插槽用 `#default`；图标名 `Search` 形式 |
| 5 | **环境陷阱** | shell 有宿主注入 `SERVER__PORT=9514`，后端启动必须显式 `--server.port=8080` |
| 6 | **Redis 形态** | 免安装版在工作区 `redis/`，机器重启后需手动启动 |
| 7 | **参考红线** | jshERP GPL 协议只参考业务模型不抄代码；论文主动声明 RuoYi 基座 |
