### 4.4 库存联动事务链（第 2/3 轮实现，论文"系统实现"核心素材）

```
审核入库单（PUT /jxc/stock_in/audit/{id}，@Transactional 同事务）
  ├─ ① 现存量增加：jxc_stock upsert（唯一键 product_id+batch_no；批次成本以最新入库价为准）
  ├─ ② 库存流水：jxc_stock_flow insert（change_qty 入正、balance_qty 批次结存快照、biz_type=PURCHASE_IN）
  ├─ ③ 应付台账：jxc_payable insert（采购入库且有供应商时；盘盈不生成）
  ├─ ④ 采购订单回写：received_qty += 入库量 → 未完成行数>0 ? 状态2(部分执行) : 状态3(已执行)
  └─ ⑤ 单据状态：status→1 已审核 + audit_by/audit_time（重复审核被拒绝）
已审单保护：修改/删除被服务层拦截（"纠错请开红字或退货单"），前端同步隐藏按钮
```

### 4.5 销售出库事务链（第 4 轮实现，POS「保存即生效」）

```
开单保存（POST /jxc/sale_order，@Transactional 同事务）
  ├─ ① FEFO 拆批试算：按 expiry_date 升序（近效期先出，无效期排后）分配批次，跨批次自动拆行
  ├─ ② 主表计算：total=Σ行金额 → actual=total-优惠 → 收款状态(0未收/1部分/2已收) → status=1 直接生效
  ├─ ③ 插入主表+明细（每行含批次号与成本快照 cost_price/cost_amount —— 个别计价法）
  ├─ ④ 逐拆分行原子扣减（UPDATE ... WHERE quantity>=?，affected=0 即库存不足整单回滚）+ 流水（负数变动+结存快照，biz_type=SALE_OUT）
  └─ ⑤ 未收款>0 时必须选会员 → 生成应收台账（jxc_receivable，与应付对称）
已生效单保护：修改/删除被拦截（"销售单保存即生效，纠错请开销售退货单"）
```

**实测数据**（第 4 轮）：

- XS…001：商品1×50 + 商品4×10 → 应收 324 / 实收 200 / 部分收款；成本快照 90+340；应收台账 124 元
- XS…002：商品1×150 → **FEFO 自动拆 2 行**（P20261001 批次 50 + 空串批次 100），全款 325；库存扣至 0
- 失败事务验证：应收列名错误时整单完整回滚（库存/流水/单据零残留）——事务保护有效

### 4.6 退货红冲事务链（第 6 轮实现，"已审单纠错走红字"闭环）

```
采购退货审核（PUT /jxc/purchase_return/audit/{id}，@Transactional）
  ├─ ① 原批次原子扣减库存（不足拒绝：如 CTH…002 退 999 → "库存不足，无法退货"）
  ├─ ② 流水：PURCHASE_RETURN 出库（-qty + 结存快照）
  └─ ③ 应付红冲：负数台账记录（-170，remark 注明原入库单）——保留完整审计痕迹
销售退货审核（PUT /jxc/sale_return/audit/{id}，@Transactional）
  ├─ ① 原批次回增库存（成本沿用原销售成本快照 → 成本还原）
  ├─ ② 流水：SALE_RETURN 入库（+qty + 结存快照）
  └─ ③ 应收红冲/退款：负数台账（仅会员单；散客=现金退款不产生应收）
已审单保护：修改/删除一律拒绝（"纠错请走红字流程"）
```

**实测数据**（第 6 轮）：CTH…001（商品2 退 50）→ 库存 200→150、应付红字 -170；XTH…001（商品4 退 5）→ 库存 10→15、应收红字 -99.5、成本还原 34/件

### 4.7 盘点调整链（第 7 轮实现）

```
盘点审核（PUT /jxc/stock_check/audit/{id}，@Transactional）
  ├─ 前端体验：选商品+批次自动带出账面数量 → 录入实盘 → 差异实时计算（绿盈红亏）
  ├─ 盘盈行 → 生成盘盈入库单（{checkNo}-IN，source_type=CHECK，直接已审核）
  │           + 库存 upsert 增加 + 流水 CHECK_IN + 回写 gen_in_no
  ├─ 盘亏行 → 生成盘亏出库单（{checkNo}-OUT，source_type=CHECK，直接已审核）
  │           + 库存原子扣减（不足则整单回滚）+ 流水 CHECK_OUT + 回写 gen_out_no
  └─ 成本口径：商品档案参考进价快照（实测：商品2 进价1.5 → 盘亏3=4.50；商品4 进价12 → 盘盈3=36.00）
整单回滚验证：盘亏超量时（PD…002 冲减100>库存18）拒绝且调整单/库存/状态零变化
```

## 六、关键决策与经验记录

| # | 决策/经验         | 说明                                                                                   |
| - | ------------- | ------------------------------------------------------------------------------------ |
| 1 | **JDK8 约束**   | RuoYi-Vue 固定用 **v3.9.1**（master 3.9.2+ 需 JDK17）；构建前必须先停后端（jar 文件锁）                   |
| 2 | **前端 Vue3**   | 采用官方 RuoYi-Vue3；gitee 源需认证，克隆走 GitHub 镜像                                             |
| 3 | **代码生成路线**    | 统一 `tpl_web_type='element-plus'` 直出 Vue3 页面；主子表用 `tpl_category='sub'` + sub_table 配置 |
| 4 | **Vue3 页面规范** | `<script setup>` 页面末尾必须显式调用 `getList()`；插槽用 `#default`；图标名 `Search` 形式               |
| 5 | **环境陷阱**      | shell 有宿主注入 `SERVER__PORT=9514`，后端启动必须显式 `--server.port=8080`                        |
| 6 | **Redis 形态**  | 免安装版在工作区 `redis/`，机器重启后需手动启动                                                         |
| 7 | **参考红线**      | jshERP GPL 协议只参考业务模型不抄代码；论文主动声明 RuoYi 基座                                             |
