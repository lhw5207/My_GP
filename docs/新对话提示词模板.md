## 五、为什么这些约束必须写（给你的判断依据）

| 约束 | 来源 | 不写的后果 |
|---|---|---|
| `env -u SERVER__PORT` + `--server.port=8080` | 宿主每次注入不同值（实测 3827 / 历史 9514） | 后端起在随机端口，前端代理 502 |
| `--noproxy '*'` | 本机 http_proxy 注入（实测 3852 / 历史 6890） | curl 全部 502，误判"接口挂了" |
| 构建前停 8080 | Windows jar 文件锁 | `mvn package` 报文件占用 |
| 禁改 `utils/`、`permission.js`、`store/` | 基座鉴权链路 | 全站登录/权限失效，难回滚 |
| 禁改已审单拦截 | 审计合规（论文核心卖点） | 财务可追溯性崩塌，答辩被追问 |
| 库存变动必须写流水 | 对账口径（现存量 = Σ 流水） | 库存与账不符，验收维度 A 直接失败 |
| 事务边界不可拆 | 8 条链的一致性前提 | 部分成功 → 脏数据 |
| 更新台账 + 推 repo | 项目约定（SSOT） | 进度失真，多人协作冲突 |
